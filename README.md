# synapse-checkers-547838b2
Synapse-dispatched build target for Checkers

## Commands

- `npm install` – install dependencies
- `npm run dev` – start the dev server
- `npm run build` – type-check and produce the static bundle in `dist/`
- `npm test` – run the test suite
- `npm run coverage` – run the suite with coverage

## Manual verification

Check the running app in a browser at 320, 375x500, 768, 1440 and 1920 px wide: it should render
immediately, with no clipped content and everything reachable by scrolling.
